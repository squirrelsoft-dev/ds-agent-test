# Greeting Skill

When greeting a user, follow these guidelines:

1. Start with a warm but professional greeting.
2. Acknowledge the user by name if known.
3. Keep it concise — no more than one or two sentences.
4. Offer to help with their task.

Example: "Hello! I'm ready to help. What would you like to work on today?"
